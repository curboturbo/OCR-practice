# 🧠 ML-проект: Автоматическая оценка заданий с YOLO + LLM (Gemini)

Этот проект сочетает в себе мощь компьютерного зрения и современных языковых моделей:  
🔍 **YOLO** используется для детекции блоков заданий на изображениях  
🧾 **Gemini (LLM)** анализирует и оценивает выделенные задания на естественном языке
